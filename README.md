# 📝 JS Todo List

Современный и быстрый менеджер задач, написанный на чистом JavaScript (ES6+). Проект выполнен с использованием методологии **TDD (Test Driven Development)** и принципа разделения ответственности (Separation of Concerns).

## ✨ Особенности (Features)
- **Умный интерфейс**: Панель фильтров и счетчик задач скрываются, если список пуст.
- **Минимализм**: Добавление задач по нажатию `Enter`, скрытые кнопки удаления при наведении.
- **Фильтрация**: Быстрое переключение между всеми, активными и завершенными задачами.
- **Persistence**: Ваши задачи сохраняются в `LocalStorage` и не пропадают после перезагрузки страницы.
- **Архитектура**: Четкое разделение на бизнес-логику (`logic.js`) и управление DOM (`dom.js`).

## 🛠 Технологический стек
- **Frontend**: HTML5, CSS3 (Flexbox), JavaScript (Vanilla).
- **Testing**: QUnit (для модульного тестирования логики).
- **CI/CD**: GitHub Actions (автоматический запуск тестов при каждом push).

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/sigilisd/javascript-todo-list.git
   ```

2. Установите зависимости (нужны только для запуска тестов):
    ```bash
    npm install
    ```

3. Откройте файл index.html в любом браузере.

## Тестирование

Для запуска автоматических тестов выполните команду:
   ```bash
   npm test
   ```
